Gmail — where your mail is sent from

On Google’s screen you can pick any account — it doesn’t have to be the one you signed in with. Mails are sent from that account, appear in its Sent folder, and replies land in its inbox.
Advanced — use my own Google OAuth client

Only needed if this server has no shared Gmail client, or you don’t want to use it. Create a Web application OAuth client in Google Cloud Console, enable the Gmail API, add this redirect URI, then paste the downloaded credentials.json (or upload it).
